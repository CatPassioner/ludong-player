上传到云端共同曲库 导入说明

登录后可上传 MP3，并可同选 LRC/SRT、封面、MP4 视频（建议同名）。所有人都能听、看 MV、评论。视频建议 < 180MB。请勿上传无版权的商业音乐。

导入到我的私人空间 导入说明

私人歌只存本机当前账号。可分开上传：同一首歌请用同一绑定名——推荐「歌曲-歌名」（如 歌曲-晴天.mp3 / 歌曲-晴天.lrc / 歌曲-晴天.jpg / 歌曲-晴天.mp4），或统一「歌名 - 歌手」。漏传的文件之后按同名会自动进对应歌曲文件夹。也可一次多选；视频还可命名为 mv / video（需与 MP3 同批或已有该歌）。

软件更新 版本 —

启动时会自动检查。有新版本会提示；点立即更新即可覆盖安装，私人歌曲与账号保留。
