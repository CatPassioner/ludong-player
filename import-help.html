2. 导入到猫耳律动时怎么命名

同一首歌的文件请使用同一绑定名，分开上传也能归到同一首：

  • 推荐：歌名-歌手.mp3 / .lrc / .jpg / .mp4
  • 云端共同曲库：可单独补传或替换歌词、封面、MP3、MP4；歌名须一致，歌手可相似匹配
  • 私人空间：各扩展名保持同名即可归到同一文件夹

在软件「设置」里可上传到云端共同曲库，或导入到我的私人空间。

3. LDDC 逐字歌词怎么用

猫耳律动已支持 LDDC 导出的增强 LRC：界面整句显示，高亮按每个字的时间轴走。

  • 最省事：导出后改名为 歌名-歌手.lrc，直接上传共同曲库
  • 要整理或批量改名：打开 歌词工具，或把文件拖到 转换逐字歌词.bat

4. 注意

  • 请勿上传无版权的商业音乐到共同曲库。
  • 视频建议小于 180MB；私人空间仅保存在本机当前账号。
